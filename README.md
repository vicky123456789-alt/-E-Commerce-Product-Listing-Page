# Nexus Store – E-Commerce Product Listing Page

A responsive front-end e-commerce product listing page built using HTML, CSS, and JavaScript.  
This project simulates a real online store interface with product cards, filtering, sorting, search functionality, and a product detail modal.

This is a frontend-only project with no backend or database integration.

---

## Features

- Grid-based product listing layout
- Product cards displaying image, category, price, and rating
- Search functionality to find products by name
- Filters for:
  - Category
  - Price range
  - Minimum rating
- Sorting options:
  - Price (Low to High / High to Low)
  - Rating
  - Name (A to Z)
- Product detail modal popup
- Responsive design for desktop, tablet, and mobile screens
- Clean and modern UI styling

---

## Tech Stack

- HTML5 – Structure
- CSS3 – Styling, Flexbox, Grid, responsive layout
- JavaScript (Vanilla) – Dynamic rendering, filtering, sorting, modal logic
- Font Awesome – Icons
- Google Fonts (Poppins) – Typography
